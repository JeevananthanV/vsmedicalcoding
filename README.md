# VS Medical Coding Academy

> **Learn . Discipline . Success**

A high-converting, responsive single-page web application for **VS Medical Coding Academy** (headquartered in Salem, Tamil Nadu), built with **React.js + Vite**, **Tailwind CSS**, and **Framer Motion**.

---

## 🌟 Key Features

- **Interactive Clinical Code Simulator (Signature Feature)**: A hands-on diagnostic case mini-application where learners review real physician clinical notes, select ICD-10-CM codes, and receive instant validation with official coding guidelines.
- **Interactive 12 Human Body Systems Explorer**: Deep-dive curriculum viewer covering all 12 major biological systems, pathology concepts, and representative ICD-10-CM codes.
- **Degree Eligibility Checker**: Interactive suitability matching for Life Science, Pharmacy, Nursing, and Paramedical graduates.
- **6-Step Learning Journey Timeline**: Sequential roadmap from anatomy foundations to interview readiness.
- **Local SEO & AEO (Salem, Tamil Nadu Focus)**: Pre-configured Geo tags, `EducationalOrganization`, `Course`, and `FAQPage` JSON-LD schemas for high ranking on Google Search, Maps, and AI Answer Engines (Perplexity, ChatGPT, Gemini).
- **Sticky Mobile Conversion Bar**: Mobile-first bottom action bar providing one-tap access to WhatsApp admissions and the application form.

## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v18 or newer)
- npm or yarn

### Installation & Run

```bash
# Navigate to the frontend directory
cd frontend

# Install dependencies
npm install

# Start the development server
npm run dev
```

The application will be accessible at:
```
http://localhost:5173/
```

### Production Build

```bash
cd frontend
npm run build
npm run preview
```
