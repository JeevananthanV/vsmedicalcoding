# VS Medical Coding Academy — Setup Guide

Welcome to the **VS Medical Coding Academy** setup guide. This high-converting web application features an interactive clinical code simulator, body systems explorer, and admissions workflows built with React 18 and Vite.

- **GitHub Repository**: [https://github.com/JeevananthanV/vsmedicalcoding](https://github.com/JeevananthanV/vsmedicalcoding)
- **Author**: Jeevananthan V

---

## 📋 System Prerequisites

- **Node.js**: v18.0.0 or higher
- **npm**: v9.0.0 or higher
- **Git**: v2.30.0 or higher

---

## 📥 1. Clone the Repository

```bash
git clone https://github.com/JeevananthanV/vsmedicalcoding.git
cd vsmedicalcoding
```

---

## 📦 2. Install Dependencies & Run Locally

```bash
cd frontend
npm install
npm run dev
```

Open `http://localhost:5173` in your browser.

---

## 🏗️ 3. Production Build

```bash
cd frontend
npm run build
npm run preview
```
Output bundle is generated in `frontend/dist/`.
